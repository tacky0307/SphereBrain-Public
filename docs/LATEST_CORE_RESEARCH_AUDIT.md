# SphereBrain Unified Experience Core v2.0 — Research Audit

Publication milestone: 2026-08-22

This document separates mechanisms promoted into the current public research Core from mechanisms that remain experimental.

## Promoted into Core v2.0

- **Long-term structural memory** — learned edge weights, edge usage, and node usage.
- **Bounded working state** — a finite recent history of activity/signature/outcome state.
- **Online directed transition trace** — persistent temporal information written during transitions rather than inferred only from the final state.
- **Relational separation** — experiences are not forced into one undifferentiated value field.
- **Cluster-conditioned distributed value** — relation identities carry separate distributed consequence value fields.
- **Reliability / maturity / replasticity** — stable successful relations reduce further success plasticity; failure reopens plasticity.
- **Cross-timescale relational identity continuity** — fast and slow prototypes allow one relation identity to survive structural drift.
- **Unified persistence** — structural, short-term, temporal, relational and reliability state can be saved together.

## Evidence boundary

These mechanisms were promoted only after separate controlled experiments, ablations, counterfactual tests, or regression checks provided enough support for the general principle. Exact constants and synthetic coordinate systems are not claimed to be universal laws.

## Research-only mechanisms

The following are intentionally **not** part of the canonical public Core yet:

- exact role-conditioned forward/reverse comparator rules from the GE substrate;
- global-rank / ULP lattice thresholds;
- the exact GE109 / GE118 scalar trace coordinate;
- automatic factorized subrelation discovery;
- held-out compositional generalization;
- planning;
- predictive free-run / autonomous next-state prediction.

## Important negative findings

- Endpoint Core state alone did not reliably retain tested temporal order in GE105/GE117-style conditions; this motivated online transition memory.
- One global value field was not sufficient for stable multi-relation learning in the Sensorimotor series.
- Structural plasticity can cause one continuing relation to fragment into multiple clusters if identity is judged only by the current signature.
- Held-out relational generalization is **not yet established** in the full Unified Core.

## Unified Core v2 continuity result

Under the legacy relation assignment with structural plasticity, one observed relation was split across an average of **2.40625 clusters**, with **2.11458 assignment switches**, and the total mean cluster count was **11.1875**. With fast/slow relational continuity enabled while structural plasticity remained active, the same observed relations remained at **1.0 cluster** with **0 switches**, and the mean total cluster count fell to **3.0**. Training capacity was preserved.

This supports the general principle that a plastic Core needs a slower relational identity timescale because the representation of the same experience drifts as the structure itself changes.

## Current claim boundary

SphereBrain Unified Experience Core v2.0 is a research implementation showing that multiple validated memory and plasticity mechanisms can coexist in one experience-driven Core. It is **not** evidence of general intelligence, human-like understanding, planning, or solved compositional generalization.
